# AI Customer Review Intelligence

An NLP and machine learning project that analyses customer reviews to identify sentiment, recurring themes, and actionable product insights.

## Project Overview

This project uses natural language processing and machine learning to classify customer review sentiment and explore product feedback.

## Objectives

- Clean and prepare customer review data.
- Analyse sentiment across product categories.
- Transform text using TF-IDF.
- Train a Logistic Regression sentiment classifier.
- Identify recurring themes in customer feedback.
- Present findings through data visualisations.

## Technology Stack

- Python
- Google Colab / Jupyter Notebook
- Pandas and NumPy
- Scikit-learn
- TF-IDF
- Logistic Regression
- Natural Language Processing (NLP)

## Dataset

- Source records: 60,889
- Cleaned records: 60,886
- Positive reviews: 47,433
- Negative reviews: 9,087
- Neutral reviews: 4,366

## Model Results

| Metric | Result |
|---|---:|
| Test accuracy | 84.32% |
| Macro F1-score | 0.6779 |
| Weighted F1-score | 0.8581 |
| Test samples | 12,178 |
